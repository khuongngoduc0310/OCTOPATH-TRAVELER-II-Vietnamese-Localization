# OCTOPATH TRAVELER II Vietnamese Fan Translation — v213

Unofficial Vietnamese community localization for the Windows PC version.

## Install

Download `zzz_Octopath_Traveler2_Vietnamese_v213_P.pak`, then run `Install-Vietnamese.ps1` from the source repository or copy the PAK into `Octopath_Traveler2/Content/Paks/~mods`. Fully restart the game after installation.

## Edit and rebuild

The source archive contains editable CSVs for dialogue, GameText, character info, and item info, plus the glossary, terminology catalogs, review log, and build/install scripts. See `README.md` and `CONTRIBUTING.md`.

## Included in v213

- 30,405 dialogue rows and 14,633 GameText rows.
- Refined 107 skill/support ability names and 145 equipment names.
- Vietnamese font assets and localized UI textures.
