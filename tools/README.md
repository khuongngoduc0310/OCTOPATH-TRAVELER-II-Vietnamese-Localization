# Build tools

The installable PAK needs no extra tools. To rebuild after editing the CSV sources, use:

- **repak 0.2.3, Windows x64:** <https://github.com/trumank/repak/releases/tag/v0.2.3>. The tested ZIP SHA-256 is `6720D602144D75DF477A99D5BEDB6EA780997546AFC335901D4937CAFEAA73FA`.
- **UassetLocalize CLI:** <https://github.com/rm-NoobInCoding/UassetLocalize>. Use a release/build that supports `import`, `--engine 5.0`, `--match identity`, `--names`, and `--out`.

These tools are third-party software with their own licenses. They are not included in this source package. The build commands were verified with repak 0.2.3 and the UassetLocalize CLI bundled with the local v1.1 project tools on 2026-10-27.
